# PortSwigger SQL Injection Automation 🛡️

Este repositório contém scripts em Python desenvolvidos para automatizar a exploração de vulnerabilidades de **SQL Injection (SQLi)** nos laboratórios da plataforma **PortSwigger Web Security Academy**.

## 🛠️ Técnicas Implementadas
* **Error-Based SQL Injection:** Força o banco a gerar erros que vazam a senha.

## 🚀 Como Utilizar
Execute o script passando a URL e os Cookies:
`python3 error_based/exploit_error.py -u "URL" -s "SESSION" -t "TRACKING"`
